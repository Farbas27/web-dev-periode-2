Mijn Robot Projecten

Welkom op mijn website. Hier laat ik drie robots zien die ik interessant vind.

Ominous Battlebot

Ominous is een snelle en sterke battlebot gebouwd voor robotgevechten. Deze robot is ontworpen om tegenstanders te verslaan in de arena.

Kenmerken

  • Hoge snelheid
  • Sterk chassis
  • Gebouwd voor gevechten

Hexapod Robot

Een hexapod is een robot met zes poten. Dankzij de zes poten kan de robot stabiel lopen op verschillende ondergronden.

Kenmerken

  • Zes poten
  • Goede stabiliteit
  • Geschikt voor onderzoek

Robot Arm

Een robotarm wordt gebruikt om objecten op te pakken en nauwkeurig te verplaatsen.

Kenmerken

  • Kan objecten oppakken
  • Nauwkeurige bewegingen
  • Wordt gebruikt in fabrieken
